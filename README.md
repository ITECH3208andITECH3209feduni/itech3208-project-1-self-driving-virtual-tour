# Self Drive Virtual Tour – Avenue of Honour

## About This Project

This project is a **Self Drive Virtual Tour** for the **Avenue of Honour**.  
It allows users to explore the Avenue online using 360° images.

Users can move from one stop to another, look around the location, and learn about nearby memorial trees and the people connected to them.

The project is designed to make the Avenue of Honour easier to access for people who cannot visit the place physically.

## Main Purpose

The main purpose of this project is to create a simple virtual tour where users can:

- View the Avenue of Honour online
- Explore different tour stops
- Look around using 360° images
- Learn about nearby trees
- Understand the history of the Avenue
- Use the tour on desktop or mobile devices

## Project Features

This project includes:

- 360° virtual tour view
- Stop 1 to Stop 5 navigation
- Clickable tree hotspots
- Nearby Trees information card
- Start Tour / How to Use popup
- Simple and clean design
- Mobile-friendly buttons and layout
- Works without needing Google Street View

## Technologies Used

This project is built using:

- HTML
- CSS
- JavaScript
- 360° panorama images
- Marzipano virtual tour tool

## How to Open the Project

### Simple Method

1. Download the project folder.
2. Open the folder.
3. Double-click on `index.html` or `virtual-tour.html`.
4. The project will open in your browser.

### Using Visual Studio Code

1. Open the project folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click on `index.html`.
4. Click **Open with Live Server**.

## How to Use the Virtual Tour

1. Open the virtual tour page.
2. Click the **Start Tour** button.
3. Use the stop buttons to move between locations.
4. Click on tree hotspots to view tree/person information.
5. Read the Nearby Trees card for names close to each stop.
6. Use your mouse or finger to look around the 360° image.

## Tour Stops
