# Kingston Avenue of Honour — Virtual Tour

A web-based commemorative experience introducing the Avenue as the former Shire of Creswick Avenue of Honour at Kingston, then using the name Kingston Avenue of Honour for visitor clarity. This package contains the full website, updated through Sprint 2.

## How to run

Open `index.html` in a web browser to start. This version is prepared to work without a local server.

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Home page |
| `virtual-tour.html` | 360° Virtual Tour updated with Stops 4 and 5 |
| `tree-map.html` | Interactive map of commemorative trees |
| `profiles.html` | Profiles of those commemorated |
| `about.html` | About the Avenue |
| `resources.html` | Further resources |

## Supporting files

| File / folder | Purpose |
|---------------|---------|
| `script.js` | Tree data shared by the tour, map, and profiles |
| `stop2-data.js`, `stop3-data.js` | Panorama image data for tour stops 2 and 3 |
| `img/` | Interface icons and Stop 4/5 panorama images |
| `tiles/` | 360° panorama image tiles |
| `vendor/` | Third-party libraries |

## Sprint 2 update

The 360° Virtual Tour now includes 5 stops, with Stop 4 and Stop 5 added to the existing virtual tour page. The separate external street-view page and related navigation links have been removed from the project.
